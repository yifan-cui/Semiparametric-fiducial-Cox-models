# Semiparametric-fiducial-Cox-models
Reproduce the simulations and data application for "Semiparametric fiducial inference for Cox models"

To reproduce the simulation results, run the scripts cox1.R, cox2.R, cox3.R, and cox4.R for Models 1, 2, 3, 4, respectively.
For Table 1 (n=20), nsample <- 20, nparts = 1, nmcmc <- 400, nburn <- 40
For Table S1 (n=30), nsample <- 30, nparts = 1, nmcmc <- 400, nburn <- 40
For Table S2 (n=40), nsample <- 40, nparts = 10, nmcmc <- 1000, nburn <- 100

To reproduce the real data application, run the script survival_data_analysis.R.
