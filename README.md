# Semiparametric-fiducial-Cox-models
Reproduce the simulations and data application for "Semiparametric fiducial inference for Cox models"

To reproduce the simulation results, run the script Cox_simulation.R for Table 1.

For Table S1 (n=30), nsample <- 30

For Table S2 (n=40), nsample <- 40

To reproduce the real data application, run the script survival_data_analysis.R.
